## 작성 규칙

주차별 연구노트 파일은 다음과 같이 작성한다.

```
yyyy-mm/yyyy-mm_report_<github ID>.pdf
```

예시: `2026-02/2026-02_report_uzichoi.pdf`

| 항목 | 규칙 |
|---|---|
| 월 디렉터리 | `yyyy-mm` (하이픈). 예: `2026-02` |
| 파일명 | `yyyy-mm_report_<github ID>.pdf` |
| 재제출 | 같은 파일명으로 덮어쓴다 (버전은 git 이력에 남는다) |
| 공용 문서 | 회의록 등은 `yyyy-mm_summary.pdf` 처럼 작성한다. |
