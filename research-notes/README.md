## 작성 규칙

주차별 연구노트 파일은 다음과 같이 작성한다.

```
yyyy-mm/week-n/<github-아이디>-report.pdf
```

예시: `2026-02/week-3/uzichoi-report.pdf`

| 항목 | 규칙 |
|---|---|
| 월 디렉터리 | `yyyy-mm` (하이픈). 예: `2026-02` |
| 주차 디렉터리 | `week-1` ~ `week-5`. **그 주 월요일이 속한 달**을 기준으로, 그 달의 n번째 월요일 주 |
| 파일명 | `<github-아이디>-report.pdf` |
| 재제출 | 같은 파일명으로 덮어쓴다 (버전은 git 이력에 남는다) |
| 디렉터리 생성 | 해당 주에 먼저 올리는 사람이 `yyyy-mm/week-n/` 를 만든다 |
| 공용 문서 | 회의록 등은 `_summary.pdf` 처럼 밑줄 접두어를 붙인다 |
